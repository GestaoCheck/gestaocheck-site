Política de Privacidade

Última atualização: setembro de 2026.

Este documento explica como o site institucional do GestãoCheck (este site, em que você está agora) trata dados de quem visita. Se você é cliente ou usuário do sistema GestãoCheck (o produto em si, usado dentro da sua empresa), este documento não se aplica ao sistema — fale com quem administra sua conta para a política de privacidade do sistema.

Este site é 100% estático

Este site não tem formulário, não tem backend, não tem banco de dados e não roda nenhum script de terceiro além do necessário para exibir a página (fontes do Google Fonts e ícones via cdnjs). Isso significa, na prática:

  • O site não coleta, armazena ou processa nenhum dado pessoal seu automaticamente
  • Não existe login, cadastro ou conta neste site
  • Não usamos cookies de rastreamento, pixels de anúncio ou ferramentas de analytics
  • Não existe nenhum endpoint no servidor para enviar dados — o site só entrega as mesmas páginas HTML/CSS/JS para todo visitante

WhatsApp: a única forma de contato

Os botões "Solicitar demonstração" levam até a página de planos, onde você escolhe a opção que faz mais sentido pra sua operação. A partir dali, os botões "Quero o [plano]" e os links de contato dos fundadores abrem o WhatsApp com uma mensagem pré-preenchida, usando o link padrão wa.me. O site nunca envia essa mensagem sozinho: você decide se quer editar o texto e precisa clicar em "Enviar" dentro do próprio WhatsApp para que qualquer dado chegue até nós. A partir do momento em que você envia essa mensagem, a conversa passa a ser tratada dentro do WhatsApp, sujeita à política de privacidade do próprio WhatsApp — nós só vemos o que você decidiu nos mandar diretamente, como em qualquer conversa normal.

Dados no seu navegador

Hoje o site não usa nenhum tipo de armazenamento local do navegador (localStorage, cookies ou parecido). Se isso mudar no futuro, esta página é atualizada antes, deixando claro o que passa a ser guardado e por quê.

Imagens e dados mostrados no site

As telas do sistema mostradas neste site (capturas do próprio sistema real, em imagem ou incorporadas diretamente, vídeo de demonstração e a vitrine interativa "Veja por dentro") usam dados fictícios, criados especificamente para fins de demonstração. Nenhuma informação real de cliente aparece neste site.

Alterações nesta política

Se este site ganhar formulário, analytics ou qualquer outra forma de coleta de dados no futuro, esta página será atualizada antes disso entrar no ar, deixando claro o que passou a ser coletado e por quê.

Dúvidas

Qualquer dúvida sobre este documento, fale com a gente pelo WhatsApp através dos botões de contato deste site.
